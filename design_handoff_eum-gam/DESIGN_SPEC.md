# 음감 훈련 앱 — 디자인 명세서 (Design Brief)

> **목적**: 이 문서 하나만 보고 외부 디자이너가 앱 전체를 새로 디자인할 수 있도록, 앱의 목적·구조·기능·콘텐츠·상태·현재 비주얼 시스템·기술 제약을 빠짐없이 정리한 문서입니다.
>
> 작성 기준: 현재 코드베이스(React 18 + TypeScript + Tailwind PWA)의 실제 동작. "현재 상태"는 참고용이며, **전면 재디자인이 목표**입니다. 즉 색·타이포·레이아웃·컴포넌트 형태는 모두 새로 제안해도 됩니다. 단, **기능 구조·화면 수·입력 방식·콘텐츠·제약사항**은 유지되어야 합니다.

---

## 0. 한눈에 보기 (TL;DR)

| 항목 | 내용 |
|------|------|
| 한 줄 정의 | **교회 건반 반주자를 위한 상대음감(귀) 훈련 모바일 앱** |
| 핵심 가치 | 매일 5분, 듣고 → 맞히고 → 약점을 보강하는 반복 훈련 |
| 플랫폼 | **모바일 우선 웹앱(PWA)** · 세로(portrait) 고정 · 오프라인 동작 · 홈화면 설치 가능 |
| 언어 | **한국어** (UI 전부 한글) |
| 화면 수 | 7개 라우트 (홈 / 훈련 / 결과 / 통계 / 설정 / 실험실 / 업적) |
| 훈련 모드 | 메인 9종 + 실험실 4종 = **13종**, 각 모드 최대 10레벨 |
| 게임화 | XP · 8단계 등급 · 콤보 · 18종 업적 |
| 데이터 | 100% 로컬(localStorage), 서버/로그인 없음 |
| 톤 | 따뜻함·경건함·집중. 요란하지 않게. (교회/성가대 정서) |

## 1. 제품 개요

### 1.1 누구를 위한 앱인가
- **주 사용자**: 교회에서 건반 반주를 하거나 배우는 사람. 악보를 보고 칠 줄은 알지만 **귀로 듣고 음·화음·진행을 잡아내는 능력(상대음감)** 을 키우고 싶은 사람.
- **숙련도 범위**: 입문자(도·미·솔 구분부터)부터 중급자(7화음·조옮김·종지 식별)까지. 레벨 시스템으로 한 모드 안에서 난이도가 점진적으로 올라감.
- **사용 맥락**: 주로 스마트폰으로, 짧은 시간(한 세션 5~30문항) 집중. 통학/이동 중, 연습 전 워밍업 등. 이어폰/스피커로 소리를 들어야 함.

### 1.2 핵심 사용자 흐름 (가장 중요한 1줄)
**홈에서 모드 선택 → 레벨/옵션 설정 → "시작하기"(오디오 로딩) → [듣기 → 답 입력 → 정·오답 피드백] × N문항 → 결과 화면(점수·획득 XP·새 업적) → 홈/재도전.**

### 1.3 디자인이 풀어야 할 문제 (현재의 약점 = 재디자인 기회)
- 화면이 카드 나열식이라 **위계가 약하고 정보가 평면적**으로 보임.
- 모드가 13종이라 **홈의 모드 선택부가 복잡**해 보일 수 있음 → 그룹핑/시각적 구분 필요.
- 훈련 화면이 모드마다 입력 UI가 달라 **일관성 설계**가 핵심 과제.
- 게임화 요소(XP·콤보·업적)가 있으나 **동기부여로서의 임팩트가 약함** → 보상 연출 강화 여지.
- 이모지에 과하게 의존(아이콘 시스템 부재) → **전용 아이콘/일러스트 세트** 제안 환영.

## 2. 플랫폼·기술 제약 (디자인 시 반드시 고려)

| 제약 | 디자인 함의 |
|------|-------------|
| **모바일 세로 고정** (`orientation: portrait`) | 모든 화면은 1열 세로 스크롤. 가로 레이아웃 불필요. 기준 폭 ~390px, 콘텐츠 최대폭 `max-w-lg`(512px) 중앙 정렬. |
| **PWA / 오프라인** | 홈화면 아이콘, 스플래시(테마컬러), standalone 모드. iOS 노치 안전영역(`safe-area-inset`) 고려. 설치 유도 카드 필요. |
| **터치 우선** | 탭 타깃 최소 44×44px. 보기 버튼 `min-h 64px`. 피아노 건반 등 정밀 입력은 가로 스크롤. |
| **오디오 중심 앱** | 소리가 본질. "듣기" 버튼이 항상 눈에 띄어야 함. 첫 진입 시 오디오/샘플 로딩 상태 필요(브라우저 정책상 사용자 탭 후 재생). |
| **한국어 폰트** | 본문 `Noto Sans KR`, 디스플레이/큰 숫자 `Noto Serif KR`. 한글 가독성·줄바꿈 고려. |
| **라이트 모드 only (현재)** | 다크모드는 `darkMode: 'class'` 훅만 있고 미구현. **다크모드 대응 디자인을 제안하면 가산점.** |
| **모션 접근성** | `prefers-reduced-motion` 존중. 모든 애니메이션은 끌 수 있어야 함. |
| **저사양 기기** | 발열/배터리 이슈 이력 있음 → 무거운 상시 애니메이션·고비용 블러 남발 지양. |

기술 스택(참고): React 18, Tailwind CSS, Tone.js(피아노 샘플 오디오), VexFlow(오선보), Recharts(통계 차트), Zustand(상태/localStorage), React Router(HashRouter).

## 3. 정보 구조 (사이트맵)

```
홈 (/)
├── 훈련 (/train/:mode)          ← 모드 13종이 모두 이 화면을 공유
│     ├── 설정(setup) 단계        ← 레벨·옵션 선택 + 오디오 시작
│     └── 훈련(training) 단계      ← 듣기 → 입력 → 피드백 반복
│           └── → 결과 (/result)  ← 세션 종료 시
├── 실험실 (/lab)                ← 보조 모드 4종 허브
│     └── → 훈련 (/train/lab-*)
├── 통계 (/stats)
├── 설정 (/settings)
└── 업적 & 등급 (/badges)
```

            └───┬───────────┬───────────┬───────────┬──────────┬─────────┘
                │           │           │           │          │

## 4. 현재 비주얼 시스템 (디자인 토큰 — 재정의 대상)

> 아래는 **현재** 값입니다. 디자이너는 이를 출발점/참고로 보고 새 시스템을 제안하면 됩니다. 컨셉 키워드는 **"피아노 잉크(딥 인디고) + 황동 골드 + 상아/종이 크림"** — 경건하고 따뜻한 클래식 무드.

### 4.1 컬러 팔레트
| 역할 | 의미 | 주요 값 |
|------|------|--------|
| **Primary (딥 인디고)** | 검은 건반·잉크·경건함 | 500 `#6366f1` · 600 `#4f46e5` · 700 `#4338ca` · 800 `#3730a3` · 900 `#312e81` · 950 `#1e1b4b`(본문 텍스트) |
| **Accent (골드)** | 황동·성가대 빛·따뜻함 | 300 `#fcd34d` · 400 `#fbbf24` · 500 `#f59e0b` · 700 `#b45309` |
| **Canvas (크림 배경)** | 종이/상아 (순백 대신) | 50 `#fdfcf8`(앱 배경) · 100 `#faf8f1` · 200 `#f3efe2`(경계선) |
| **Success (세이지 그린)** | 정답 (차분하게) | 500 `#22c55e` · 600 `#16a34a` · 700 `#15803d` |
| **Danger (웜 로즈)** | 오답 (공격적이지 않게) | 500 `#f43f5e` · 600 `#e11d48` · 700 `#be123c` |
| 모드별 액센트 띠 | 모드 구분색 (모드카드 상단 4px 띠) | 계명 골드 `#f59e0b` · 음정 인디고 `#6366f1` · 코드 바이올렛 `#8b5cf6` · 진행 핑크 `#ec4899` · 멜로디 틸 `#14b8a6` · 조옮김 오렌지 `#f97316` · 리듬 시안 `#06b6d4` · 템포 에메랄드 `#10b981` · BPM 로즈 `#f43f5e` |
| PWA 테마컬러 | 상태바/스플래시 | `#3730a3` (배경 `#fdfcf8`) |

### 4.2 타이포그래피
- 본문/UI: **Noto Sans KR** (400/500/600/700/900)
- 디스플레이(헤드라인·큰 숫자·정답률): **Noto Serif KR** (`font-display`)
- 큰 숫자 스케일: `display-sm` 2.5rem / `display` 3.5rem / `display-lg` 4.75rem (모두 굵게, 음수 자간, 행간 1)
- 숫자는 `tabular-nums`(고정폭) + `ss01` 적용해 정렬감 유지.

### 4.3 형태·그림자·모션
- 모서리: 카드 `rounded-2xl`(16px)/hero `rounded-3xl`(24px), 버튼 `rounded-xl`(12px), 칩/뱃지 `rounded-full`.
- 그림자(인디고 톤이 살짝 섞인 따뜻한 그림자): `soft`(미세) / `card`(기본 카드) / `lifted`(부각) / `glow-primary`·`glow-accent`(포커스/선택 링).
- 애니메이션: `fade-in`(0.2s), `slide-up`(0.3s, 카드 등장), `bounce-in`(0.4s, 보상 연출), `pop`(0.35s, +XP/정답 강조), `shake`(0.4s, 오답).
- 버튼 공통: 탭 시 `active:scale-95` 눌림 피드백.

## 5. 공통 컴포넌트 카탈로그

> 디자이너는 아래 컴포넌트 각각의 **기본/호버/선택/정답/오답/비활성/포커스** 상태를 정의해야 합니다.

### 5.1 버튼
| 종류 | 용도 | 현재 스타일 |
|------|------|------------|
| Primary | 주 액션("시작하기","듣기","다음") | 인디고 600 배경, 흰 글자, 라운드 xl |
| Secondary | 보조 액션("통계","설정","한번더") | 흰 배경, 인디고 테두리/글자 |
| Accent | 강조(거의 미사용, 골드) | 골드 500 배경 |
| Ghost | 약한 액션("뒤로","건너뛰기","다시 입력") | 무배경 회색 글자, 호버 시 옅은 배경 |

### 5.2 카드
- `card`: 기본 흰 카드(설정 항목, 통계 패널 등).
- `card-hero`: 크림 그라데이션 + 강한 그림자(등급 카드, 결과 점수, 요약 통계).

### 5.3 보기 그리드 (ChoiceGrid) — 선다형 입력의 핵심
- 2/3/4열 그리드. 각 보기 버튼은 `라벨(굵게) + 보조설명(작게)` 구조.
- 좌상단에 번호(1~9) 표시(키보드 단축키 힌트).
- 상태: 기본 / 선택됨(인디고 글로우) / 정답(세이지+✓+pop) / 오답(로즈+✗+shake) / 정답공개 시 나머지 흐려짐(opacity 50).
- 접근성: radiogroup, 숫자키·방향키·Enter 지원.

### 5.4 피아노 건반 (Piano) — 멜로디/계명 입력
- 가로 스크롤 피아노. 흰 건반 44×120px, 검은 건반 28×75px, 기본 3~5옥타브.
- 좌우 `‹ ›` 옥타브 이동 버튼. 각 건반에 음이름 라벨.
- 건반 상태색: 입력강조(인디고) / 정답(에메랄드) / 오답(레드). 이명동음(예: Bb=A#) 자동 매칭.
- 컴퓨터 키보드 매핑도 지원(a~k 흰건반, w·e·t·y·u 검은건반).

### 5.5 재생 컨트롤 (PlaybackControls)
- 중앙 큰 **"▶ 듣기"**(Primary, 가장 중요한 버튼). 로딩 시 스피너.
- 좌측 선택적 **"🎹 기준음"**(Ghost) — 기준음 설정이 켜진 모드에서만.
- 우측 **속도 토글**: 보통(🐇) ↔ 느리게(🐢, 0.5배).

### 5.6 진행 바 (ProgressBar)
- 훈련 화면 상단. `현재/전체` 진행 + `✓정답수` 표시.

### 5.7 콤보 오버레이 (ComboOverlay)
- 3연속 이상부터 등장하는 알약형 배지. 단계별 색·이모지 상승:
  - 3연속 🔥 오렌지 / 5연속 ⚡ 앰버 / 10연속 💎 시안 / 20연속 👑 퍼플.
  - 등장 시 `bounce-in`.

### 5.8 토스트 (Toast)
- 일시 알림(성공/정보/오류). 데이터 내보내기·가져오기·초기화 결과 등.

### 5.9 뱃지/칩
- `badge-primary`(인디고) / `badge-accent`(골드) / `badge-muted`(회색). 조성 표시, 약점 집중 표시 등.

## 6. 화면별 상세 명세

### 6.1 홈 (`/`)
**목적**: 진입 허브. 동기부여(등급/통계) + 빠른 시작(모드/약점) 제공.

구성(위→아래):
1. **헤더**: 인디고 그라데이션 배경, 흰 글자. 상단 작은 골드 라벨 "EAR TRAINING" + 제목 **"음감 훈련"**(serif) + 부제 "교회 반주자를 위한 귀 훈련".
2. **등급 & XP 카드**(XP>0일 때만, 탭 시 업적 화면): 현재 등급(이모지+이름) / 누적 XP / 다음 등급까지 진행 바(인디고→골드 그라데이션).
3. **최근 획득 업적 스트립**(있을 때): 최근 3개 업적 아이콘 + "전체 →".
4. **요약 통계 카드**(세션>0): 전체 정답률(%) · 세션 수 · 총 문제 — 3분할, 큰 숫자.
5. **빈 상태**(첫 사용자, 세션=0): 🎼 + "훈련을 시작해보세요" 환영 카드.
6. **약점 보강 숏컷**(약점 있을 때): 골드 카드. 약점 항목 최대 3개 리스트(모드·항목명·약점점수) → 탭 시 약점 집중 세션 시작. "전체 보기 →"(통계).
7. **모드 그리드**: "훈련 선택" 라벨 아래 2열 카드. 카드마다 상단 모드색 띠 + 이모지 + 모드명 + 한줄 설명 + (기록 있으면)정답률 미니 바, (없으면)"아직 기록 없음". 카드 10개(메인 9 + 실험실 진입 1).
8. **하단 탭**: "📊 통계" / "⚙️ 설정" 2버튼.

상태: 신규 사용자(통계/약점/업적 카드 숨김, 환영 카드 노출) vs 기존 사용자(전부 노출).

### 6.2 훈련 (`/train/:mode`) — 앱의 심장부
두 단계로 구성: **설정(setup)** → **훈련(training)**. 13개 모드가 이 화면을 공유하며, 입력 영역만 모드별로 달라짐.

#### 6.2-A 설정 단계 (오디오 시작 전)
- 상단 바: "← 뒤로" + 모드명.
- 중앙: 큰 모드 이모지 + 모드명.
- (약점 세션이면) "⚡ 약점 집중 세션 · N문항" 배지.
- **사용법 카드**: 모드별 한 문단 설명(아래 7장 howTo 참조).
- **레벨 선택 카드**: 1~10을 5×2 그리드 버튼으로. 선택 시 인디고. 하단에 "Lv{n} · {레벨 라벨}" 설명.
- **절대음감 토글 카드**(음정/코드/계명/진행/멜로디/조옮김/실험실 등 음높이 모드만): "기준음 없이 음이름만 듣고 맞히기" 스위치.
- **(진행 모드만) 출제 소스 선택**: "일반 다이어토닉" vs "🙏 찬양 패턴".
- 하단 큰 **"🎵 시작하기"** 버튼 + "첫 시작 시 피아노 샘플을 불러옵니다" 안내. 로딩 중엔 "🎵 소리 준비 중...".

#### 6.2-B 훈련 단계
- **상단 헤더**: "← 나가기" + 모드명·Lv + (약점이면)배지. 아래 진행 바(현재/전체·✓정답수). 오디오 폴백 시 경고 배너("피아노 샘플 못 불러옴, 기본 음색으로 재생").
- **재생 컨트롤**(5.5): 듣기 / 기준음 / 속도.
- **조성 배지**(해당 모드): "조성: C장조".
- **입력 영역**(모드별, 6.2-C 참조).
- **피드백 패널**(답 제출 후): 정답(✅ 세이지)/오답(❌ 로즈) + 정답 표기 + (부분정답 시)%. 우측 **"+XP" 플로터**(pop). 모드별 상세 피드백(반음 수·헷갈림 힌트·오선보 등). 콤보≥3이면 콤보 오버레이.
- **하단 버튼**: 미응답 시 "건너뛰기"(ghost), 피드백 시 "다음 →" 또는 마지막이면 "결과 보기 →".

#### 6.2-C 모드별 입력 방식 (디자인 일관성 핵심)
| 입력 유형 | 사용 모드 | UI |
|-----------|----------|-----|
| **선다형(ChoiceGrid)** | 음정, 코드, 계명(계이름 모드), 실험실 4종 | 보기 그리드. 탭 즉시 채점. |
| **피아노 건반** | 멜로디(여러 음 순서 입력), 계명(건반 모드) | 음 개수만큼 누르면 자동 제출. 입력한 음 칩 표시 + "다시 입력". |
| **계명 입력방식 토글** | 계명 | "🔤 계이름" ↔ "🎹 건반" 세그먼트 토글. |
| **도수 시퀀스(1~7 버튼)** | 조옮김 | 7개 도수 버튼. 들은 음 수만큼 입력. 입력 칩 + 다시입력. |
| **도수+화음질 그리드** | 코드 진행 | I,ii,iii,IV,V,vi,vii° 등 4열 버튼. 코드 수만큼 입력. 표기는 로마/넘버 설정 따름. |
| **탭(두드리기)** | 리듬, 템포 | 큰 탭 버튼(👋/🥁). 카운트인 표시. 들은 박/리듬대로 두드림. |
| **BPM 추정** | BPM 맞히기 | 레벨 1~6: 4지선다 버튼 / 레벨 7~10: 슬라이더 + 현재값 큰 숫자 + 제출. |

피드백 단계의 정답 공개: 선다형은 정답 하이라이트, 피아노/도수는 정답/오답 음 색칠, 진행은 정답 칩 나열.

### 6.3 결과 (`/result`)

구성:

3. **점수 카드**: 큰 이모지(🏆/🎉/💪/📚, 점수대별) + 큰 정답률(%) + 격려 문구. 정답/오답/소요시간 3분할. 최고 콤보≥3이면 "🔥 최고 콤보 N연속" 칩.

6. **액션 버튼**: "한 번 더"(Primary) / "🏆 업적 보기" / "📊 통계 보기" / "홈으로".

점수대별 연출: 90%+ 🏆"완벽합니다!" / 70%+ 🎉"잘 하셨어요!" / 50%+ 💪"계속 연습해보세요!" / 그 외 📚"약점을 집중 훈련해봐요!".

## 8. 게임화 시스템

### 8.1 XP
한 문항마다 `난이도(레벨) + 정답여부(부분점수 60% 반영) + 속도보너스(3~10초 선형) × 콤보배수(연속당 +10%, 최대 2배)` 로 XP 부여. 레벨1 약 12점 ~ 레벨10 약 48점 + 보너스.

### 8.2 등급(8단계) — 누적 XP 기준
| 등급 | 이모지 | 필요 XP |
|------|--------|---------|
| 브론즈 I / II / III | 🥉 | 0 / 200 / 500 |
| 실버 | 🥈 | 1,200 |
| 골드 | 🥇 | 3,000 |
| 플래티넘 | 💠 | 8,000 |
| 다이아 | 💎 | 20,000 |
| 마스터 | 👑 | 50,000 |

### 8.3 콤보(연속 정답)
세션 내 연속 정답 시 3/5/10/20 단계에서 오버레이 연출(🔥/⚡/💎/👑). 오답·부분정답·건너뛰기 시 리셋.

### 8.4 업적 18종 (6 카테고리)
| 카테고리 | 업적 | 조건 |
|----------|------|------|
| 누적(volume) | 첫 정답🌱 / 10🪴 / 100🌳 / 500🏛️ / 1000🏔️ | 누적 정답 수 |

## 9. 상태·피드백 정의 (디자이너가 모두 다뤄야 할 상태)

- **로딩**: 오디오 샘플 로딩("🎵 소리 준비 중..."), 재생 중 스피너, 라우트 전환 스피너(RouteSpinner).
- **오디오 폴백**: 피아노 샘플 실패 시 경고 배너(소리는 기본 음색으로 정상 출력).
- **정답/오답/부분정답**: 색·아이콘·애니메이션(pop/shake) + 정답 표기 + 부분% + 모드별 상세(반음 차이, 헷갈림 힌트, 오선보, 박자 오차 등).
- **빈 상태**: 홈(신규 환영), 통계(기록 없음).
- **확인 상태**: 기록 초기화 2단계 확인.
- **PWA 설치 상태**: 설치 가능 / iOS 안내 / 이미 설치됨(카드 숨김).
- **접근성/모션**: reduced-motion 시 애니메이션 정지, 포커스 링(키보드만), radiogroup·aria 라벨.

## 10. 톤 & 마이크로카피 가이드

- **언어**: 한국어. 따뜻하고 격려하는 어조("잘 하셨어요!", "약점을 집중 훈련해봐요!"). 명령형보다 권유형.
